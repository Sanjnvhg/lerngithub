# lerngithub

• Version Control (ควบคุมเวอร์ชัน): บันทึกการเปลี่ยนแปลงโค้ดทุกครั้ง (Commit) สามารถย้อนดูหรือย้อนกลับไปเวอร์ชันเก่าได้ทันที
• Cloud Backup (สำรองข้อมูลบนคลาวด์): เก็บรักษาโค้ดไว้บนเซิร์ฟเวอร์ออนไลน์ ป้องกันข้อมูลสูญหายแม้คอมพิวเตอร์พัง
• Collaboration (ทำงานร่วมกันเป็นทีม): หลายคนสามารถช่วยกันเขียนโค้ดในโปรเจกต์เดียวกัน ทำ Pull Request เพื่อรีวิวโค้ดก่อนรวมเข้าด้วยกัน
• GitHub Actions (ระบบอัตโนมัติ / CI/CD): ช่วยทดสอบ ตรวจสอบ และ deploy โค้ดโดยอัตโนมัติ
• GitHub Copilot (ผู้ช่วย AI): ช่วยเขียนโค้ด แชทถามปัญหา ทำโค้ดรีวิว และระบบอัตโนมัติด้วย AI
• GitHub Pages: สามารถสร้างและเผยแพร่เว็บไซต์แบบ Static ฟรีได้โดยตรงจาก Repository
ถ้าคุณสนใจใช้งาน สามารถบอกได้เลยว่าต้องการทราบเรื่องไหนเป็นพิเศษ เช่น:
• วิธี Git push / clone เบื้องต้น
• การสร้าง Repository แรก
• การใช้งาน GitHub Copilot หรือ GitHub Pages
